Super Admins can grant granular permissions to each Admin individually. Rather than every Admin having identical access, you decide exactly what each person can do within your organization.

## Where to configure permissions

Go to **Settings → Users**, click the Admin you want to configure, then click **Edit permissions**. Changes take effect immediately.

<Warning>
  Removing a permission takes effect immediately. The Admin will lose access to that action as soon
  as you save.
</Warning>

## All permissions

## Always-on permissions

`canViewSchedule` and `canViewStaff` are always enabled for all roles and cannot be removed. Every authenticated member of your organization can view the schedule and the staff roster.

## Super Admin-only permissions

The following permissions are reserved for Super Admins and cannot be delegated to Admins:

- **canManageUsers** - add, remove, and manage organization members
- **canConfigureAdminPermissions** - configure which permissions each Admin has
- **canManageOrgSettings** - edit organization name, address, phone, and timezone
