An Admin can do only what their Super Admin switches on for them. Permissions are set per person, not per team, so two Admins can have different access.

## Changing an Admin's permissions

A Super Admin opens the Admin on **People** and selects **Edit admin access**. The **Edit permissions** dialog lists each area of DubGrid with a **View** and an **Edit** switch. Turning on **Edit** includes **View**. **Select All** and **Clear All** set everything at once, and a count shows how many are on.

Nobody can change their own permissions.

## The areas

| Area                              | View                                                     | Edit                                                                                                                                     |
| --------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Schedule**                      | Always on                                                | Edit shifts and schedule notes                                                                                                           |
| **Publish schedule**              |                                                          | Publish the schedule                                                                                                                     |
| **Recurring shifts**              | See recurring schedules                                  | Change recurring schedules, apply them with Auto Fill, and manage repeating shifts. Applying and repeating also need **Schedule: Edit**. |
| **Staff**                         | See staff details: contact, account, and access          | Add, edit, import, and change the status of staff, and invite people                                                                     |
| **Shift requests**                | Included                                                 | Approve and reject requests                                                                                                              |
| **Coverage**                      | See coverage requirements                                | Change coverage requirements                                                                                                             |
| **Departments & labels**          | See departments, focus areas, and labels                 | Change them                                                                                                                              |
| **Shifts, jobs & schedule notes** | See shifts, jobs, absence types, and schedule note types | Change them                                                                                                                              |
| **Dashboard**                     | See dashboard analytics                                  |                                                                                                                                          |
| **Reports**                       | Run and export reports                                   |                                                                                                                                          |

Seeing everyone's requests comes with approving requests, **Staff: Edit**, or **Schedule: Edit**. Dashboard analytics also come with editing shifts, publishing, managing staff, or approving requests.

## What a new Admin starts with

Editing shifts and schedule notes, publishing, recurring shifts and repeating shifts, applying recurring schedules, the dashboard, and reports. Everything else starts off.

## What only a Super Admin can do

Changing roles and Admin permissions, **Organization Details**, **Shift Display Mode**, **Schedule Rules**, billing, the **Activity Log**, and deleting the organization. These can't be given to an Admin. See [Roles and permissions](/reference/roles).
