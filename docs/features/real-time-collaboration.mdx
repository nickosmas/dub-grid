---
title: "Real-Time Collaboration"
description: "Multiple schedulers can work on the same schedule simultaneously, changes sync instantly across all open sessions."
---

DubGrid keeps every user on the same page in real time. When one scheduler makes a change, every other open session sees it immediately, no manual refresh required.

<Note>
  Real-time collaboration requires an active internet connection. If your connection drops, DubGrid
  will automatically catch up with any missed changes when you reconnect.
</Note>

## Presence avatars

Colored avatars appear in the schedule toolbar to show who else is currently viewing the schedule. Each avatar represents an active user session. Hover over an avatar to see the user's name.

Presence avatars update automatically as users join or leave the schedule view.

## Cell locks

When a user opens a cell for editing, that cell is locked for everyone else. A lock indicator appears directly on the cell, showing the name and avatar of the user currently editing it. Other users cannot edit a locked cell until the editor closes the shift panel and the lock releases.

Cell locks prevent two people from overwriting each other's changes at the same time.

## Live sync

Changes made by any user, new shifts, edits, deletions, propagate to all open sessions in real time. The grid updates without any page reload or manual action on your part.

This applies to:

- Draft shift changes
- Published schedule updates
- Discard actions

## Cross-tab coordination

If you have the schedule open in multiple browser tabs at the same time, all tabs stay in sync with each other. An action taken in one tab is immediately reflected in the others.
