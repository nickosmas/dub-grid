**Settings > Organization Details** holds your organization's basic profile. Only a Super Admin can see and change it.

## Who can open Settings

A Super Admin can open every part of **Settings**. An Admin sees the **Settings** tab only if their Super Admin has given them at least one settings permission, and then only the sections those permissions cover; anything they can see but not change is marked read-only. Admins start with no settings permissions. Users don't see **Settings**.

Some settings are for Super Admins only: **Organization Details**, **Shift Display Mode**, **Schedule Rules**, **Activity Log**, and **Delete Organization**.

## The details

| Field                 | Notes                                                                   |
| --------------------- | ----------------------------------------------------------------------- |
| **Organization name** | Required, up to 60 characters.                                          |
| **Phone**             | Optional.                                                               |
| **Address**           | Two address lines, city, state or province, postal code, and country.   |
| **Time Zone**         | Suggested from the address when it's filled in automatically.           |
| **Employees**         | A count, for information. Staff are managed on [People](/staff/roster). |

Your organization's web address (its subdomain) isn't set here. The two-week pay period is set in [Schedule Rules](/configuration/schedule-rules-and-display).

## Saving changes

Select **Review & Save**. The **Review Organization Changes** dialog lists what you changed so you can confirm it, since it affects everyone in your organization. **Discard** throws away changes you haven't saved.
