## Compatibility with the deployed code

080 drops and recreates `create_shift_series`, `update_series_all_shifts` and
`delete_shift_series` with extra parameters, each defaulted. `main` at
`98055cd8` (release #164) calls them with 9, 3 and 2 named arguments. Those
exact calls, made on the local database with 080 applied as the QA Super Admin
in a rolled-back transaction, created 5 cells, updated all 5, then removed 5
and archived the series, as before 080. So 080 can be applied ahead of the
release that uses it, and must be: code from `730de23d` on sends
`p_keep_existing`, `p_origin_date`, `p_from_date` and `p_to_date`, which the
079 functions do not accept.
