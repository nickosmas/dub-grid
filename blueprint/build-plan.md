> already exists, so most items below start checked to reflect reality.

## Shipped

- [x] 1. **Multi-tenant organizations** - subdomain-isolated tenants, each
      with its own settings and terminology overrides
- [x] 2. **Four-tier RBAC** - Gridmaster / Super Admin / Admin / User,
      with per-person configurable admin permissions (25-key set)
- [x] 3. **Schedule grid** - drag-drop week / 2-week / month views with a
      draft/publish workflow and recurring shifts
- [x] 4. **Real-time schedule collaboration** - Supabase Realtime cell
      locks and presence
- [x] 5. **Staff / people management** - lifecycle, focus areas,
      certifications
- [x] 6. **Shift requests** - pickup, swap, and call-off with approval
      workflow and auditable request events/snapshots
- [x] 7. **Coverage tracking and dashboard analytics** - shared coverage
      engine used by both web and mobile
- [x] 8. **Reports** - staff hours, staff activity, shift-category
      breakdowns, CSV/PDF export
- [x] 9. **Gridmaster portal** - cross-org platform administration,
      impersonation, audit logs
- [x] 10. **Billing** - Stripe per-seat subscriptions with a 14-day free
      trial
- [x] 11. **Mobile app parity** - Expo app covering schedule, people,
      requests, alerts, and dashboard
- [x] 12. **Invite-only onboarding** - pre-confirmed account creation via
      the invitation flow, no public self-serve signup

      per-session org isolation
- [x] 14. **Notification inbox**
- [x] 15. **Print / export** - PDF, CSV, and .ics output
- [x] 16. **Test sandbox** - cookie-based cloned org for safe QA
